Install a custom language pack

Place the trusted JSON manifest in ~/.local/share/crap-mcp/languages/. For a local grammar, also copy the WASM file to the path named in the manifest. On macOS restart the service with launchctl kickstart -k gui/$(id -u)/com.crap-score.machine, then reload this page, select the pack, and save.
