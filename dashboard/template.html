    How the session score works

    Each remaining affected function earns up to 2.5 points each for CRAP ≤ 30, complexity below 10, nesting below 4, and the fraction of measured lines covered. We average those points across functions. Higher is better. Missing coverage gives a range; skipped files prevent a grade. This local rubric does not measure correctness or reproduce CodeScene Code Health.
